## 4. Indexación / GEO — prerender estático con `vite-react-ssg` (cambio mayor)

**Problema:** el sitio era un SPA (HTML vacío). Los crawlers de IA (GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot) y Bingbot no ejecutan JS → todo el contenido era invisible.

**Solución:** prerender estático por ruta en el build, **sin migrar a Next.js** y sin reescribir componentes. Dominio canónico: `https://www.flainube.mx`.

**Dependencia:** `vite-react-ssg@0.8.9` (pineada; compatible con react-router-dom 6.30.4 y React 18.3.1, **no** se actualizó ninguno).

### Archivos nuevos
| Archivo | Qué hace |
|---|---|
| [src/seo/pages.ts](src/seo/pages.ts) | **Fuente única de SEO**: meta por ruta, sitemap y prerender derivan de aquí. Incluye la regla anti-SSR-inseguro. |
| [src/seo/RouteSeo.tsx](src/seo/RouteSeo.tsx) | Inyecta `<head>` por ruta (title, description, OG, Twitter, canonical, hreflang, noindex) + **JSON-LD** en el HTML del build. |
| [public/robots.txt](public/robots.txt) | Permite explícitamente GPTBot, ClaudeBot, OAI-SearchBot, Claude-SearchBot, PerplexityBot, Google-Extended, Bingbot, Googlebot + línea `Sitemap:`. |
| [public/llms.txt](public/llms.txt) | Resumen + índice del sitio para herramientas de IA. |
| `.github/workflows/build.yml` (raíz del repo) | CI: `npm ci` + `npm run build` en cada push/PR; falla si el build falla (atrapa código SSR-inseguro). |
| [.npmrc](.npmrc) | `legacy-peer-deps=true` (para que Vercel/Netlify instalen sin ERESOLVE). |

### Decisiones SEO
- `/inicio` y `/asesor-cloud` = app (no marketing) → **noindex** + fuera del sitemap.
- Duplicados (`/recursos/white-papers`, `/blog`) → `canonical → /recursos/documentacion`, fuera del sitemap.
- **6 sectores de industria** (`/industries/{gobierno,banca-finanzas,salud,manufactura,retail,educacion}`) → prerenderizados con `canonical → /industries`, fuera del sitemap. Corrige una regresión: en estático no resolvían (404) sin su HTML.
- `/partners` → placeholder prerenderizado (`noindex`) para evitar 404 del enlace del Sidebar.
- **404 real** (`/404` → `dist/404.html`) con `noindex`.
- JSON-LD: `Organization` en todas, `WebSite` en `/`, `Service` en las 11 familias, `BreadcrumbList` internas. Campos `sameAs`, `dataCenters` (→ `Organization.location`) y og-image quedan como TODO en `pages.ts` para llenar.

### Verificación del build (Fase 4)
- **30 páginas** prerenderizadas, cada una con contenido real, 1 `<h1>`, title único, canonical y robots correctos.
- **JSON-LD válido** en todas (parsean sin error).
- **sitemap.xml = 18 URLs** (excluye app, 404, duplicados y sectores).
- **CLS medido con Chrome DevTools Protocol** (`offsetTop` del `.dashboard` a 100 ms y 2500 ms) = **Δ 0 px**.
- `npm run dev` funciona igual y el Hero anima idéntico.
